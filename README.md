# CF Pocket

把算法竞赛练习装进口袋。支持 iOS 和 Android，在手机上读题、看题解、写代码、跑样例，追踪自己的训练进度。

**[下载最新版 Android APK](https://github.com/NuclearSoap114/CFPocket/releases/latest)** · Android 10 及以上

## 主要功能

- **读题与题解**：浏览 Codeforces 题目、官方材料和洛谷社区题解，支持 Markdown、公式与图片。
- **难度按需显示**：CF 难度、标签和洛谷等级默认隐藏，点击展开，配色与平台等级对应。
- **手机写代码**：C++ 高亮、括号补全、代码片段、个人模板、数字与符号辅助栏、撤销重做。
- **本地跑样例**：内置 C++ / Python 运行环境，用绿色 AC、红色 WA 直观展示结果。
- **Codeforces 提交**：在 App 内登录、选择语言、提交代码并查看官方判题结果。
- **训练题单与进度**：导入 Obsidian Markdown 题单，关联文件夹后同步勾选进度。
- **训练统计**：多 OJ 记录、热力图、难度分布和进度统计，支持数据导入与导出。
- **可选 AI 助教**：翻译题面、获取提示、讨论思路与代码；使用自己配置的 AI 服务。

支持浅色与深色模式。本地样例通过不等于官网 AC；C++ 本地运行环境与 Codeforces 有差异。

## 安装

Android：在 [Releases](https://github.com/NuclearSoap114/CFPocket/releases/latest) 下载 `.apk` 并安装。首次安装若被系统拦截，请为下载使用的浏览器或文件管理器允许“安装未知应用”。建议保持 Android System WebView 更新。

iOS：目前通过 Xcode 构建安装，最低 iOS 18.4。详见[开发说明](docs/DEVELOPMENT.md)。
